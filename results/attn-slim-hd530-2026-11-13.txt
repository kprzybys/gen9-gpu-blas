== 2. Plan per category (what can go, what not) ==
- address/header adds (Qwen 64, Llama/whisper 32 per block, (1|M0) :q, one per send): the two K headers (NK 2) and the
  two V headers (Qwen, D/64 = 2) sit in adjacent registers; one (2|M0) :q add with dst <4> (32 B apart) advances both.
  Llama/whisper V (one header): two headers for even/odd key steps, one (2|M0) add of 2*rs every second step.
  -> Qwen 32, Llama 16 adds. Needs isa.REGION to accept dst <4> (isa.py, requested separately).
- loop counter/cmp/jmpi (3) + mask rem/cmp/jmpi (3): counter add + cmp moved before the softmax with flag f1.1, the
  mask jumps on the same flag (the last block always takes the mask path, harmless: rem = 16 masks nothing) -> 4.
  Unrolling by 2 key blocks: saves 1.5 instructions per block, doubles code, needs n_k % 32 or a tail; registers are at
  the solver bound (11.1: Llama 2 left, Qwen 2 left) -> not worth it.
- softmax max reduction (sel 4 per row) + cmp/jmpi per row: rows reduced together through 2-register regions,
  one cmp (RQ) and one .any<RQ>h jump; per-row test only inside the rare rescale path -> Qwen 8+4 -> 5+2,
  Llama 16+8 -> 8+2.
- S zero (mov 0, RQ*NK SIMD8): first K mad of the block as mul (as GEMM b6b3b3e) -> 0. loopcheck's attention mode
  loses the first (K, Q) product of a mul-started chain: rule requested separately.
- s - m add, exp, l += p, p odd copy (RQ*NK each): no removal without changing the arithmetic (s - m before exp is the
  math; both parities of p are needed because each V block read covers 4 consecutive GRF of both parities; l must
  be summed). Starting S from -m_old would change the rounding order -> not done.
- hoisting: nothing loop-invariant is left in the loop (Q permutation, header zeroing already before it).
- rescale path: unchanged arithmetic, executed rarely (not in 'dyn').
