# userptr and fixed call cost on the HD 530 (GPU without IOMMU), 2026-11-12
# Machine: Intel HD Graphics 530 (Skylake-S GT2, Gen9, PCI 0x1912, 24 EU), Core i5-6500 (4 cores), DDR4-2133 2 channels (2 x 8 GB,
#   34.1 GB/s theoretical), desktop without a monitor, Ubuntu 26.04.1, Linux 7.0.0-34-generic, i915, Python 3.14.4, NumPy 2.3.5,
#   OpenBLAS 0.3.32. Code at fb1e1e2; lib/kernels.c built on the UHD 620 (-device whl), md5 02e260eb5c20ceabb31ea0335da2255e.
# IOMMU: enabled for other devices (DMA-FQ), NOT for the GPU (no graphics DMAR unit; 00:02.0 in no IOMMU group). The UHD 620
#   laptop has the GPU behind the IOMMU (DMA-FQ). GPU under load: 1000 MHz (max 1050). CPU governor powersave, EPP balance_performance.
# The machine runs its own services (about 30% of one core in total); every run at nice 19 / ionice idle, OPENBLAS_NUM_THREADS=1.
#   No display on this GPU. First file for this machine: results/skylake-hd530-2026-11-12.txt.

## Summary
# - Page pinning (userptr execbuf, 64 MB in + 64 MB out = 32 768 pages, PHASES=1): first call 14.7-15.7 ms CPU (~0.46 us/page,
#   like the UHD 620), following calls 2.9-3.7 ms (~0.09-0.11 us/page; one outlier 9.2 ms) [MEAS]. On the UHD 620 (GPU behind
#   the IOMMU) all four calls were 14-27 ms (~0.45 us/page, results/userptr-2026-11-12.txt) [MEAS]. The laptop file does not
#   separate the first call from the rest, so the comparison of warm calls is the one that holds: about 4-5x cheaper here.
#   Attribution to the IOMMU (dma_map per page) is a hypothesis: the CPUs differ too, but memcpy (copy column below) is
#   slower here than on the laptop, so a faster CPU does not explain it. Why the first call costs the same here is unknown.
# - Library: "new" cases (pages pinned again) use 0.6x the CPU of the laptop: sgemm n=4096 new 2.83 vs 4.52 ms, axpy n=1e7
#   new 2.29 vs 4.11 ms [MEAS]. userptr vs copy ratios are otherwise like on the laptop.
# - Fixed call cost (axpy n=4096 from C): 59-64 us wall / 26-30 us CPU; execbuf 12-14 us, GEM_WAIT 40 us wall / 6-7 us CPU,
#   command building 5-6 us, userptr lookup 0.5 us [MEAS]. Laptop on mains: 48 us / 14-17 us CPU, execbuf 8 us, GEM_WAIT
#   35 / 3.9 us, building 2.4 us (results/overhead-2026-11-12.txt) -- this desktop CPU at powersave is slower per call;
#   not investigated (the governor/C-states differ; no root here).
