## 4. What had to change (each found by a failing run)
- weak *definitions* `const int kcl_nprograms_gen12 = 0` in kcl.c were folded to 0 by GCC: the linked table was never
  seen ("no built-in program hgemm.cl"); now weak references (extern, address NULL when absent). Same for Gen8.
- userptr with I915_USERPTR_READ_ONLY -> ENODEV on Gen12 (Linux gt/gen8_ppgtt.c:1025, no read-only PTEs on Gen11/12):
  userptr objects are writable there; read-only mappings are detected through /proc/self/maps and copied instead.
- packed layouts: the OpenCL C hgemm_v reads A as a plain 16x16 tile (pk_a2 wrote the A2 layout of gen_h.bin; result
  was garbage), sgemm_v the plain layout of GEN8_PLAIN_PACK: tgllp compiles with -DPLAIN_PACK_A2 / -DGEN8_PLAIN_PACK.
- lib/CMakeLists.txt: an empty GEN9BLAS_KERNEL_CACHE made cached_tables.py take "--key" as its cache directory and serve
  a stale table (pre-existing; now "-" means off).
