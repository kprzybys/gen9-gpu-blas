## 6. Not found / open

1. **Whether an LRI to 0xB134 from a user batch changes anything** on this machine: the PRM lists it as user-writable and Mesa
   writes it, but NEO does not, and i915 leaves the hardware default (0xD0000020 default = all-client pool). Needs a measurement.
2. **The exact 26.27.39122.x patch level** installed on the target (tags .10-.14 exist); the NEO sources here are .14.
3. **gmmlib version pinned by NEO 26.27** (22.10.2 used); MOCS index chosen for `OCL_BUFFER` is derived from the table search, not from a run.
4. **L3 size mismatch** (1920 KB reported vs 2880 KB in the PRM for 1x3x16) and DSS count reported by i915 for I915_PARAM_SUBSLICE_TOTAL.
5. **Stepping/revision of the 0x9a78 part** (decides whether NEO's A0..B-only barrier workarounds apply).
6. IGC `waClearHDCWrite`: condition `Wa_1807084924`; the WA table content for TGL in IGC 2.40.14 was not fetched.
7. PRM **EU ISA details** (`dp4a`, `mac/mach` accumulator rules, exact SWSB encoding bits) were not extracted; IGA ModelXe.hpp was not downloaded
   (only listed in `igc-2.40.14/tree.json`).
8. Local ocloc cannot compile for Gen12, so no real Gen12 `.ze_info` was inspected; section 4 is derived from NEO's decoder and IGC.
9. PRM v1, v5, v10-v13 not downloaded (not needed). x.org docs index has no TGL directory.
